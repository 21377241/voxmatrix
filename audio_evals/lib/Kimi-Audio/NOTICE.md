# Kimi-Audio inference subset

This directory contains the inference files used by the VoxMatrix Kimi-Audio
adapter. Training, evaluation-toolkit, Docker, demo, and image assets from the
upstream repository are intentionally excluded.

Upstream project: <https://github.com/MoonshotAI/Kimi-Audio>

The upstream license statement is:

Files retain upstream copyright and license headers where provided. Model
weights are not included and remain subject to their own terms.
