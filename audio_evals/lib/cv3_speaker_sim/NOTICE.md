# 3D-Speaker inference subset

The code under `3D-Speaker/speakerlab/` is a reduced inference subset of the
3D-Speaker project:

<https://github.com/modelscope/3D-Speaker>

The retained source headers identify the work as Copyright 3D-Speaker and
licensed under the Apache License, Version 2.0. A copy of that license is
available in the VoxMatrix repository root.

Training recipes, runtime deployment examples, pretrained weights, and
standalone demo scripts are not distributed in this snapshot.
