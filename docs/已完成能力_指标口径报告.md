### 指令 / pred / ref 形态

```text
指令: [audio enroll] [audio test]
      Determine whether both recordings contain the same speaker.
      Return JSON only as {"same_speaker": true, "score": 0.0},
      where score is confidence from 0 to 1 that they are the same speaker.
pred: {"same_speaker": true/false, "score": 0.0–1.0}
      （可带 ```json 围栏；有 score 时后续判定以 score 为准）
ref:  label / text ∈ {0,1}；same_speaker bool；reference_obj 含二者
→ 样本级抽出 verification_score / verification_label
→ MeshAgg：overall/eer、overall/auc；acc@0.5 仅诊断
```

### 指标

| 指标 | 角色 | 含义 | 好坏 |
|---|---|---|---|
| **EER** | **主指标** | 扫描阈值使 FAR≈FRR，取平均错误率 | **越小越好**（0 完美） |
| **AUC** | 辅主指标 | 随机一对（同人分、异人分）中同人分更高的概率 | **越大越好**（1 完美，0.5 随机） |
| `speaker_verification_acc` | 诊断 | 固定阈值 0.5：`score≥0.5` 判同人后与金标比对 | 仅对照，不当主分 |

算分要点（`SpeakerVerificationEvaluator` + MeshAgg）：

1. 解析 JSON，取值优先级：`score` → `similarity` → `same_speaker` → 原文。
2. 得到 `verification_score`（浮点）与 `verification_label`（1=同人，0=异人）。
3. **acc@0.5**：`predicted = (score ≥ 0.5)`，样本级 0/1 再平均。
4. **EER**：按金标拆成同人/异人两组 score；对候选阈值 \(t\) 算  
   \(\mathrm{FAR}(t)=\#\{\text{异人且 }score\ge t\}/\#\text{异人}\)，  
   \(\mathrm{FRR}(t)=\#\{\text{同人且 }score< t\}/\#\text{同人}\)；  
   取 \(|\mathrm{FAR}-\mathrm{FRR}|\) 最小处的 \((\mathrm{FAR}+\mathrm{FRR})/2\)。
5. **AUC**：Mann–Whitney 式，对每个同人分 \(p\)、异人分 \(n\)：\(p>n\to1\)，\(p=n\to0.5\)，\(p<n\to0\)，再除以对数。

`min_dcf` 未实现，本能力不评。

### 为什么主分不用 acc@0.5

- **阈值任意**：同一套分数排序，换门槛（0.5 / 0.3 / 0.7）acc 会变；Omni 分数常两极（0.95 / 0.1），固定 0.5 不能代表「分得开」。
- **官方 verification 协议报 EER/AUC**，不是固定阈值 accuracy。
- **acc 丢校准信息**：`score=0.51` 与 `0.99` 在 acc 里同为对；EER/AUC 看相对排序与最优门槛错误率。
- 小样本上 acc 噪声大；EER/AUC 更贴近「同人分是否整体高于异人分」。

因此：**EER 为主、AUC 为辅、acc@0.5 仅 diagnostic**。

### Smoke 参考

### 指令 / pred / ref 形态

```text

      Return JSON only … {"segments":[{"start":<s>,"end":<s>,"speaker":"<id>"}]}
