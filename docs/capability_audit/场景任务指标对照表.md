## 指标计算详解（pred 怎么和 ref 比）

统一约定：

- **pred** = 模型输出（解析后）
- **ref** = 金标 / reference
- 多数指标先做简单归一化（大小写、标点、空白）；中文 CER 按字，英文 WER 按词
- **语料级** = 整集汇总；**样本级** = 单条 0/1 或单条分数再平均

### 1. CER / WER（asr、long_form_asr）

比的是「转写字符串」和「参考转写」。

1. 规范化 pred、ref（去多余空格等；中文常去标点后按字）
2. 把字符串切成单元：
   - **CER**：按**字/字符**
   - **WER**：按**词**（英文空格分词）
3. 算最小编辑距离：把 pred 改成 ref 需要多少次 **插入 / 删除 / 替换**
4. \[
   \mathrm{CER\ 或\ WER}=\frac{\text{插入}+\text{删除}+\text{替换}}{\text{ref 单元数}}
   \]
5. 常报告为百分比（×100）。**越小越好**（0 = 完全一致）

例：ref=`今天气温不正常`，pred=`今天气温不正常啊`  
若按字：多 1 个插入 → CER = 1/7 ≈ 14.3%。

中文主报 CER，英文主报 WER；两者数值不可直接横比。

---

### 2. BLEU / chrF（speech_translation）

比的是「模型译文」和「参考译文」（**不是**和源语音频比）。

**BLEU（越大越好，通常 0–100）**

1. 看 pred 里有多少 n-gram（连续 1～4 词/字）也出现在 ref 里 → 得到精确率 \(p_1\ldots p_4\)
2. 几何平均，再乘**长度惩罚 BP**（译文过短会扣分）
3. 英文用 `13a` 分词，中文用 `zh` 分词 → **zh→en 与 en→zh 的 BLEU 不能横比**
4. 本框架常用 **语料级** sacreBLEU（整集一起算），不是 10 条单条 BLEU 再平均

**chrF（越大越好）**

1. 在**字符** n-gram 上算精确率与召回率，合成 F 分
2. 对措辞差一点更宽容（如 `worldwide` vs `around the world`）
3. 本轮作 BLEU 的辅指标

例：ref=`The weather is nice today.`，pred=`Weather is nice today.`  
词级有重叠 → BLEU 不会是 0；比整句换说法时 chrF 往往比 BLEU 高。

COMET 需 (源文, 译文, ref) 三元组，盘面未统一接入，本表不展开。

---

### 3. speaker_count_acc

1. 从 pred 解析出整数人数（纯数字或 JSON `count`）
2. 与 ref 人数比较：相等 → 1，否则 → 0
3. 语料分 = 各条平均。**越大越好**

例：ref=`3`，pred=`3` → 1；pred=`2` → 0。

---

### 4. EER / AUC（speaker_verification、spoof_detection）

每条先抽出：

- `verification_score`：同人/真实的置信度（越高越倾向「同人」或「真人」）
- `verification_label`：金标，1=正类（同人 / bonafide），0=负类（异人 / spoof）

**acc@0.5（仅对照）**：`score ≥ 0.5` 判正类，再和金标比对错。

**EER（越小越好）**

1. 正类分数列表 / 负类分数列表
2. 扫描阈值 \(t\)：
   - FAR = 负类里 `score ≥ t` 的比例（误当成正类）
   - FRR = 正类里 `score < t` 的比例（漏掉正类）
3. 选使 |FAR−FRR| 最小的 \(t\)，EER = (FAR+FRR)/2

**AUC（越大越好，随机≈0.5）**

对每个正类分 \(p\)、负类分 \(n\)：\(p>n\) 得 1，相等 0.5，否则 0；再除以正×负对数。  
含义：随机抽一对，正类分更高的概率。

实现：`SpeakerVerificationEvaluator` + `MeshAgg._write_verification_metrics`。

---

### 5. DER（diarization）

比的是「谁在什么时段说话」的时间轴，不是转写文字。

1. pred / ref 都解析为 `segments[{start, end, speaker}]`
2. 用所有起止时刻切成小时间片
3. 每个时间片上看 ref 说话人、pred 说话人；speaker id 允许**最优置换**（speaker_1 可对齐到 A 或 B）
4. 样本级：
   \[
   \mathrm{DER}=\frac{\text{说话人不一致的时间长度}}{\text{ref 上有人说话的时间长度}}
   \]
5. 语料级：各条 error 时长求和 / 各条参考时长求和（**按时长加权**，不是简单平均每条 DER）

**越小越好**。框架是依赖无关的近似 DER；正式榜可用 pyannote 复核。

---

### 6. cpCER / attribution_acc（speaker_attribution）

比的是「这句话是谁说的」+「说了什么」。

1. pred / ref 为带 `speaker` 的 utterance 列表
2. 在说话人之间做最优匹配（置换）
3. **attribution_acc**：匹配后 speaker 是否对上的比例
4. **cpCER**：按说话人拼接文本后算 CER（说话人错了也会拉高错误）

---

### 7. target_speaker_acc / mis_execution

1. pred 解析是否应执行（bool / JSON）
2. 与 ref `should_execute` 比较 → **target_speaker_acc**
3. **mis_execution**：本不该执行却执行了（误响应）的比率

---

### 8. EM / text_f1 / qa-exist-match（qa 等）

均在文本归一化之后：

| 指标 | 规则 | 松紧 |
|------|------|------|
| **EM** | pred 整串 == ref 整串 → 1 else 0 | 最严 |
| **text_f1** | 按 token 算精确率/召回的 F1 | 中等 |
| **qa-exist-match** | 归一化后，一方字符串包含另一方（或短答命中）→ 1 | 较松 |

语料分多为准确率（平均）。code_switch 短答轨本轮用 qa-exist-match；长答轨用 ROUGE-L。

---

### 9. ROUGE-L（摘要 / 长答）

1. 找 pred 与 ref 的**最长公共子序列**（不必连续）
2. 由此算召回、精确，合成 F 分 → ROUGE-L  
**越大越好**。meeting_summary 协议主指标；当前盘面零数据。

---

### 10. accuracy / macro_f1（分类：场景、事件、副语言…）

- **accuracy**：pred 标签 == ref 标签的比例
- **macro_f1**：每个类别先算 F1，再对类别平均（类别不平衡时比 accuracy 稳）

多标签事件：按标签集合比，再聚合成 micro/macro（实现随 evaluator）。

---

### 11. constraint_satisfaction / tool_acc（指令与工具，bing T4）

`capability_protocols.v2.yaml` 合入 `origin/bing` 后的主指标：

1. **constraint_satisfaction**（instruction_following）：约束/IFEval 类满足率，不再用 intent_acc / slot_f1 作默认主指标
2. **tool_acc**：调用的工具名是否正确
3. **parameter_acc / parameter_f1**：参数字段是否对齐
4. **call_exact_match**：整次 tool call 是否完全匹配
5. **task_success**：仍用于 navigation / calendar 等场景化 agent 子能力，不是 tool_call / 多轮的默认主指标

---

### 12. llm_judge / clarification_* / IHBench（多轮 / 澄清 / 打断）

- **multi_turn_dialogue**：`llm_judge`（需 API）
- **clarification**：`clarification_accuracy` 及 precision / recall / F1
- **interruption**：`tf_win_score`、`rq_pass`（IHBench 量规，需 API）

不同 benchmark 判分器不同，不能跨集直接比绝对分。

---

### 13. speech_generation 相关

生成的是**音频**，常二次度量：

| 维度 | 大致做法 |
|------|----------|
| content_acc | 生成音 → ASR → 与目标文本比 CER/WER 或匹配 |
| intelligibility | 可懂度模型/人工 |
| SIM | 与参考音色 embedding 余弦相似 |
| MOS / DNSMOS | 自然度预测分 |

---

### 14. MER（code_switch 理想主榜，当前 N/A）

混语转写专用错误率：在统一分词/语言标记后对 pred↔ref 做编辑距离类计算。盘面缺 SEAME 类混语转写 gold，本轮未出 MER。
